# RentRide - Rent Ride  Website
A group project for the IICT at FAST NUCES ISLAMABAD.

## Project Theme
Car Rental Website

## Project Description
Rent Ride is a car rental website that allows users to explore cars, save their favourite cars, manage their accounts, and access special deals and student discounts.
